# Stockroom – Inventory & Dashboard Management System

A lightweight, fully-responsive Single Page Application (SPA) designed to manage inventory, track stock movements, and visualize operational data in real time.

## 🌐 Live Demo
[View Live Demo](https://Balthiam.github.io/stockroom-dashboard/)

## ✨ Key Features
- **Role-Based Access Control (RBAC):** Admin, Editor, and Viewer roles with SHA-256 client-side password hashing.
- **Data Analytics:** Dynamic bar and donut charts powered by Chart.js (Stock Value & Status).
- **Inventory CRUD:** Add, edit, and delete items with stock validation rules.
- **Audit Log System:** Real-time logging for stock updates, additions, and deletions.
- **Advanced UI/UX:** Live multi-criteria filtering, dynamic column sorting, dark mode, toast notifications, and CSV export.

## 🛠️ Tech Stack
- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (Custom Properties & Flexbox/Grid)
- **Security & Data:** Web Crypto API (`SHA-256`), LocalStorage API
- **Libraries:** Chart.js
